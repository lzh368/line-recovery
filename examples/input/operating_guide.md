# 设备基础指南 · recovery-0.1

本指南是演示工位公开规则，不是厂家规格或生产设备操作规程。资料为合成。

## 设备与范围

CV-01 是长 2.4 m、宽 0.5 m 的直线纸箱输送段，M-01 使用 24 V DC 驱动支路。
控制器有独立供电；上游电源可用、驱动支路接通、驱动就绪是三个不同状态。
本设备不使用电池，所以没有剩余电量百分比。只分析这一工位，不诊断外部电网和未提供资料的机械内部部件。

## 公开参考

| 项目 | 本演示工位参考 |
| --- | --- |
| 驱动工作电压 | 22.8～25.2 V；上游电源存在不代表支路有电 |
| 驱动无电反馈 | ≤1 V 且支路使能关闭，可作为供电未接通的证据 |
| 目标带速 | 0.4 m/s；稳态参考 0.38～0.42 m/s |
| 停稳带速 | ≤0.02 m/s；失去供电后有不超过 2 s 的本例减速记录 |
| 稳态电机电流 | 1.2～2.2 A，只适用于已供电、运行指令有效且启动宽限结束 |
| 启动宽限 | 从实际启动边沿起 3 s；未看到边沿不能自行假定已过宽限 |
| 驱动柜温度 | 50 °C 预警，60 °C 温控暂停；≤45 °C 持续30 s才允许后端判定温度恢复就绪，缺样中断计时 |
| 标称过箱节拍 | 稳态约 2 s/箱；空载试运行和启动阶段不套用 |
| 状态新鲜度 | 后端时钟与 captured_at 比较，最长 30 s，且不得晚于 expires_at |

## 字段与图片

- 运行请求、生产任务需求和远程恢复许可分别记录。运行请求可能被保护撤销，而生产需求仍存在。
- 计划停机、维护、急停、区域条件不明都不能按“缺电就接通”处理。
- 在制箱数 = 入口累计 − 出口累计 − 人工移出累计。本窗计数不清零，无旁路。
- CSV 是 1 Hz 快照；0/1 为布尔记录，空值是未观测，不是 0。JSON null 也表示未知。
- 图片只说明该时点可见纸箱分布，不能证明运动、供电、连续时间状态或现场安全。背景货架上的物品不计入本输送段在制箱数。
- device_state.json 是上传时的快照。它的许可、时效和 revision 只描述当时，执行前必须从工具重新查询。

## 工具调用的公共边界

power-control 提供 get_device_status、resume_conveyor；cooling-control 提供 get_cooling_status、start_cooling。当前均只是计划接口。后端校验可信状态、现场许可、防护、急停、维护锁定、通道条件及版本，不能使用上传文件自授权限。
来电后驱动可以重新就绪，但输送不会自动启动。恢复运行须单独获准；恢复产出须在新的观察中看到出口计数增加。供电恢复、运动恢复、产出恢复分开记录。
柜内独立风机的命令、运行反馈、故障和控制许可单独记录。开启风机不代表温度已经下降；温度恢复和运行许可由可信后端核验，不能由图片或模型自报。
不得解除急停或维护锁定、绕过保护、反复复位，或把命令受理当作恢复成功。错误、拒绝和无反馈必须如实报告。
